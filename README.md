# LLM Security Lab

## Objective
Learn LLM security through practical Python experiments.

## Technologies
- Python
- Groq API
- python-dotenv
- Git and GitHub

## Current Progress
- Created a Python virtual environment
- Configured environment variables
- Made a successful LLM API request
- Tested an S3 cloud security question

## Security Practices
- API keys are stored outside source code.
- The .env file is excluded from Git.
- Never commit real credentials.
